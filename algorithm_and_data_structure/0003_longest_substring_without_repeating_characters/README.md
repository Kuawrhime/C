# 3. Longest Substring Without Repeating Characters

Find the length of the longest substring without repeating characters.

## Example

```
"abcabcbb" -> 3 ("abc")
"bbbbb" -> 1 ("b")
"pwwkew" -> 3 ("wke")
```

## Build and test

```
make            # compiles the object file
make tests_run   # Criterion unit tests
```
